# Regenerated holdout-attack records, seeds 1 to 19

The holdout attack's archived records are the 20-seed summary `../e7_multiseed_summary.json`,
written by `e7_multiseed.py`, and the per-seed records for seed 0, `../e7cal_seed0.json` and
`../e7scal_seed0.json`. `e7_multiseed.py` computes the per-seed results in memory and stores only
their aggregate, so per-seed records for seeds 1 to 19 were never written when the summary was
produced.

The 38 files in this directory are those records, regenerated on 2026-10-03 from the code in
this repository with

    python3 experiments/cp_experiments.py e7cal  --scale full --seed S --model cnn --out e7cal_seedS.json
    python3 experiments/cp_experiments.py e7scal --scale full --seed S --model cnn --out e7scal_seedS.json

for S = 1, ..., 19, against the ARC-TGI generators at the pinned commit `d8a2621`. The attack is
pure NumPy and is determined by its seed.

Two checks tie the regenerated records to the archived ones, and `summarize_witnesses.py` runs the
second on every invocation:

1. Seed 0 regenerated by the same command equals the archived seed-0 records in every field except
   the wall-clock field `_wallclock_sec`.
2. Seed 0 from the archive together with seeds 1 to 19 from this directory reproduce every value
   of `e7_multiseed_summary.json`: each gap mean, standard deviation, 95% half-width, minimum and
   maximum, each threshold, and each count of winning or crossing seeds.

These records are regenerated, not archived from the original run. The paper's numbers are read
from the archived summary.
